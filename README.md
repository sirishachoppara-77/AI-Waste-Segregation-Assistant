
# AI-Based Waste Segregation & Awareness Assistant 🌱

## Overview
This project was developed as part of the **1M1B – IBM SkillsBuild AI for Sustainability Virtual Internship**.
It demonstrates how AI can be used to address real-world sustainability challenges, specifically waste segregation.

## SDG Alignment
- **SDG 12:** Responsible Consumption and Production  
- SDG 11: Sustainable Cities and Communities  
- SDG 13: Climate Action  

## Problem Statement
Improper waste segregation leads to increased landfill usage, pollution, and inefficient recycling.
Many people lack awareness of how to correctly dispose of different types of waste.

## Solution
The AI-based assistant interacts with users through a conversational interface.
Users enter a waste item, and the system:
- Classifies the waste (Biodegradable / Recyclable / Hazardous)
- Recommends the correct disposal method
- Explains the environmental impact

## AI Elements Used
- Rule-based AI classification
- Decision-support logic
- Conversational AI interaction
- Sustainability reasoning

## Technologies
- Python
- Rule-based AI logic

## Responsible AI
- No personal data collection
- Transparent and explainable logic
- Sustainability-focused guidance
